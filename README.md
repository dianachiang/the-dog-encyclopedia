# 🐕 The Dog Encyclopedia

The Dog Encyclopedia is a Python App that provides comprehensive information about dog breeds using the API-Ninjas Dogs API. This app is created for the NYU Stern Programming for Python Class during the Summer 2026 Semester. 

## 📋 Project Description

This app allows users to search for any dog breed and receive detailed information including:
- Physical characteristics (height, weight, lifespan)
- Behavioral trait ratings on a 1-5 scale
- Image URL to see a picture of the dog


## 🛠️ API used
- API-Ninjas - Free dog breed database API
